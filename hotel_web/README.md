# Отель «Морской бриз» — веб-приложение на Flask

## Что нового в этой версии
- Регистрация и вход пользователей (пароли хранятся в зашифрованном виде).
- Каталог номеров с картинками, описанием и ценой за сутки + фильтр по категориям.
- Бронирование в два клика: выбрать номер → дата и количество суток → готово.
- Личный кабинет «Мои брони» с отменой брони.
- Отзывы гостей о номерах.
- Админ-панель: статистика, управление номерами (добавить/изменить/удалить),
  бронями (сменить статус, удалить), гостями и отзывами.

## Как запустить (по шагам)

1. **Создайте базу.** Откройте файл `hotel.sql` в MySQL Workbench
   и выполните весь скрипт (значок молнии ⚡). Скрипт пересоздаёт базу
   `hotel_db` и наполняет её тестовыми данными.

2. **Установите библиотеки.** Откройте командную строку в папке проекта:
   ```
   pip install -r requirements.txt
   ```

3. **Укажите пароль MySQL.** Откройте `app.py`, найдите строку
   ```
   db = Database(host="localhost", user="root", password="", database="hotel_db")
   ```
   и впишите свой пароль от MySQL в кавычки.

4. **Запустите сайт:**
   ```
   python app.py
   ```
   Откройте в браузере: http://127.0.0.1:5000

## Учётные записи
- Админ: логин `admin`, пароль `admin123`
- Гость: логин `user`, пароль `user123`
- Новые пользователи регистрируются на странице «Регистрация».

## Тестовые купоны
`WELCOME10`, `SUMMER15`, `NO-DISCOUNT` — вводятся при бронировании.

## Как отправить в новую ветку на GitHub
```
git add .

git checkout -b web-app
git push -u origin web-app
```

## Структура проекта
- `hotel.sql` — схема базы + данные
- `db.py` — классы для работы с БД (весь SQL здесь)
- `app.py` — маршруты Flask (вся логика страниц)
- `templates/` — HTML-шаблоны (обычные — для гостей, admin/ — для админа)
- `static/style.css` — оформление
- `static/img/` — картинки номеров
