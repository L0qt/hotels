**Grand Hotel** — это полноценное веб-приложение для управления отелем, написанное на Python (Flask). 
Проект включает в себя две роли (Администратор и Гость), систему бронирования номеров с фотогалереей, ресторан с доставкой еды в номер, систему отзывов и мощную админ-панель с тотальным контролем.

---

## ✨ Основные фишки и функционал

### 👤 Панель Гостя (Пользователя)
*   **Регистрация и авторизация**: Личный кабинет с возможностью редактирования профиля (ФИО, телефон, email).
*   **Бронирование номеров**: Выбор дат заезда/выезда, автоматический подсчет итоговой стоимости.
*   **Фотогалерея**: На странице номера работает карусель с листанием нескольких фотографий.
*   **Ресторан**: Меню с блюдами. Если у вас есть активная бронь, вы можете заказать еду прямо в номер.
*   **Отзывы**: Возможность оставить оценку и комментарий к номеру.

### 🛠️ Панель Администратора (Тотальный контроль)
*   **Дашборд**: Статистика по выручке, количеству броней, заказов еды и пользователей.
*   **Управление номерами**: 
    *   Добавление новых номеров с **загрузкой нескольких фото** прямо с компьютера.
    *   Редактирование любых параметров (цена, описание, замена фотографий).
    *   Лимит номеров (по умолчанию **10 штук**).
*   **Управление меню ресторана**: Добавление, редактирование и удаление блюд с загрузкой фото.
*   **Управление бронями**: Изменение статуса (Забронировано / Оплачено / Выселен), дат заезда/выезда и итоговой суммы.
*   **Управление пользователями (CRM)**: Назначение роли «Администратор», удаление пользователей из базы.
*   **Модерация**: Удаление любых отзывов, которые нарушают правила.

## 🚀 Инструкция по запуску (Для чайников)

Для запуска вам понадобится только **Python** и браузер. База данных (SQLite) создастся автоматически при первом запуске!

### Шаг 1: Подготовка
1. Скачайте и распакуйте папку с проектом (`grand_hotel_web`).
2. Убедитесь, что у вас установлен [Python](https://www.python.org/downloads/). *Важно: при установке поставьте галочку `Add Python to PATH`*.

### Шаг 2: Установка библиотек
1. Откройте терминал (командную строку) в папке с проектом. 
   * *Как это сделать:* Откройте папку с проектом, кликните по адресной строке сверху, введите `cmd` и нажмите `Enter`.
2. Введите команду для установки Flask:
   ```bash
   pip install -r requirements.txt
