# 🏨 Grand Hotel - Веб-приложение для управления отелем

![Python](https://img.shields.io/badge/Python-3.8%2B-blue?style=for-the-badge&logo=python)
![Flask](https://img.shields.io/badge/Flask-3.0.0-green?style=for-the-badge&logo=flask)
![SQLite](https://img.shields.io/badge/SQLite-3-lightgrey?style=for-the-badge&logo=sqlite)
![Bootstrap](https://img.shields.io/badge/Bootstrap-5.3-purple?style=for-the-badge&logo=bootstrap)

**Grand Hotel** — это полноценное веб-приложение для управления отелем, написанное на Python (Flask). 
Проект включает в себя две роли (Администратор и Гость), систему бронирования номеров с фотогалереей, ресторан с доставкой еды в номер, систему отзывов и мощную админ-панель с тотальным контролем.

> 💡 **Главная фишка проекта:** 
> Приложение использует встроенную базу данных **SQLite**. Это значит, что вам **НЕ НУЖНО** скачивать и устанавливать MySQL, настраивать пароли и серверы. База данных (`hotel.db`) создастся автоматически при первом запуске!

## 🖼️ Как загружать фотографии (Инструкция)

Все картинки загружаются **прямо через сайт в браузере** (никаких папок и кода!).

### Для НОВЫХ номеров и блюд:
1. Зайдите на сайт как Админ (`admin`/`admin`).
2. В верхнем меню нажмите **«Админ Панель»**.
3. Нажмите **«Добавить номер»** (или «Добавить блюдо»).
4. В поле «Фотографии» нажмите на кнопку выбора файла. 
5. Вы можете выбрать **сразу несколько фото** (зажмите `Ctrl` на клавиатуре, чтобы выделить несколько файлов сразу). 
6. Нажмите «Сохранить». На странице номера появится карусель с листанием!

### Как заменить фото у СУЩЕСТВУЮЩИХ номеров:
1. В админ-панели перейдите во вкладку «Номера».
2. Нажмите кнопку **«Изменить»** (✏️) под нужным номером.
3. Вы увидите текущие фото. Чтобы их заменить, выберите новые файлы в поле «Загрузить новые фото».
4. *Совет:* Если вы хотите поменять только цену или описание, просто **не трогайте** поле с файлами. Старые фото останутся на месте.

> **💡 Поддерживаемые форматы:** `.jpg`, `.jpeg`, `.png`, `.webp`. 
> Рекомендуемый размер фото: 1000x800 пикселей (не загружайте файлы тяжелее 5 МБ, чтобы сайт работал быстро).
