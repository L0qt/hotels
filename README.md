ЧАСТЬ 1. ЧТО ИЗМЕНИЛОСЬ В ПРОЕКТЕ
==============================================================

Было: одно десктопное приложение на tkinter (файл
hotel_mysql_app.py), где весь код в одном файле и данные
вводятся вручную.

Стало: полноценное веб-приложение с разделением ролей.


ОСНОВНЫЕ ИЗМЕНЕНИЯ:

[1] Разделение на классы (файл db.py)
    Вся работа с базой данных собрана в одном файле:
    - Database            -- подключение к MySQL, выполнение запросов
    - GuestRepository     -- гости (добавить, удалить, найти)
    - CouponRepository    -- купоны
    - BookingRepository   -- бронирования
    - RoomRepository      -- номера отеля
    - UserRepository      -- пользователи сайта (вход, регистрация)
    - StatsRepository     -- статистика для админа
    Интерфейс (страницы сайта) не пишет SQL сам --
    только обращается к этим классам.

[2] Flask вместо tkinter
    Приложение открылось в браузере по адресу
    http://127.0.0.1:5000 и работает как обычный сайт.

[3] Регистрация и вход
    Своя таблица users с ролями:
    - роль user  -- гость: видит каталог, бронирует номера,
                    управляет СВОИМИ бронями
    - роль admin -- администратор: видит всё и управляет всем
    Пароли хранятся в зашифрованном виде (хеш), а не текстом.

[4] Каталог номеров
    Карточки номеров: картинка, номер комнаты, категория
    (Стандарт, Люкс, Президентский, Семейный), характеристики,
    описание и цена за сутки. Сверху -- фильтр по категориям.

[5] Самостоятельное бронирование
    Гость выбирает номер, дату заселения и количество суток.
    Итоговая сумма считается автоматически: цена x сутки.
    Можно ввести купон (в базе есть WELCOME10 и SUMMER15).

[6] Личный кабинет "Мои брони"
    Список своих броней со статусами (Забронировано / Оплачено /
    Выселен). Свою бронь можно отменить, пока она в статусе
    "Забронировано". Можно оставить отзыв о номере: оценка и
    комментарий.

[7] Админ-панель
    - Дашборд: сколько гостей, броней, номеров, пользователей,
      выручка и свободные места -- всё на плитках статистики
    - Номера: добавить, отредактировать (кнопка с карандашом),
      удалить
    - Брони: поиск по ФИО и ID, фильтр по статусу и дате,
      смена статуса одним кликом, удаление
    - Гости и отзывы: списки, поиск, удаление


ИЗМЕНЕНИЯ В БАЗЕ ДАННЫХ (hotel.sql):

- Новая таблица users: логин, хеш пароля, роль,
  связь с гостем (поле guests_idguests)
- В таблице bookings добавлены два поля:
  "кол-во суток" и rooms_idrooms (какой номер забронирован)
- Поле "Номер телефона" сразу сделано VARCHAR(45) --
  старый ALTER TABLE из десктопной версии больше не нужен
- В конце скрипта -- блок INSERT: база наполняется тестовыми
  данными сама (8 номеров, 3 корпуса, 4 гостя, купоны, брони,
  услуги, отзывы, 2 пользователя)


ЧАСТЬ 2. КАК ЗАПУСТИТЬ -- КОРОТКАЯ ИНСТРУКЦИЯ
==============================================================

ШАГ 1. Создайте базу данных
--------------------------------------------------------------
Откройте файл hotel.sql в MySQL Workbench и нажмите кнопку
с молнией (Execute).

Внимание! Скрипт начинается с DROP SCHEMA -- старая база
hotel_db будет удалена и создана заново с тестовыми данными.
Если в старой базе есть ценные данные -- сначала сделайте
их экспорт (Server -> Data Export).

Проверка: выполните команду
    SHOW TABLES FROM hotel_db;
Должно быть 13 таблиц, включая users.

ШАГ 2. Установите библиотеки Python
--------------------------------------------------------------
Откройте командную строку (Win -> cmd), перейдите в папку
проекта и выполните:

    cd C:\путь\к\папке\hotel_web
    pip install -r requirements.txt

ШАГ 3. Впишите пароль MySQL
--------------------------------------------------------------
Откройте файл app.py в блокноте и найдите строку:

    db = Database(host="localhost", user="root",
                  password="", database="hotel_db")

Впишите свой пароль от MySQL между кавычек password="".
Больше нигде ничего менять не нужно -- весь SQL живёт в db.py.

ШАГ 4. Запустите приложение
--------------------------------------------------------------
В командной строке в папке проекта:

    python app.py

Оставьте окно открытым -- это работает сервер.

ШАГ 5. Откройте сайт в браузере
--------------------------------------------------------------

    http://127.0.0.1:5000

ШАГ 6. Войдите
--------------------------------------------------------------
Администратор:  логин admin   пароль admin123
Гость:          логин user    пароль user123

Новые пользователи регистрируются сами на странице
"Регистрация" и автоматически получают роль гостя.


ЧАСТЬ 3. ВОЗМОЖНЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ
==============================================================

Проблема: Table 'hotel_db.users' doesn't exist
Решение:  база создана старым скриптом. Выполните hotel.sql
          из этой версии (ШАГ 1).

Проблема: Access denied for user 'root'@'localhost'
Решение:  неверный пароль MySQL. Проверьте ШАГ 3.

Проблема: ModuleNotFoundError: No module named 'flask'
Решение:  библиотеки не установлены. Повторите ШАГ 2.

Проблема: Error loading MySQLdb / mysql.connector
Решение:  выполните: pip install mysql-connector-python

Проблема: порт 5000 занят
Решение:  перезапустите python app.py или закройте другое
          приложение, использующее этот порт.

Если ошибка другая -- пришлите её текст или скриншот.
